Le bouton prend toujours l'installeur de la dernière version publiée sur GitHub (`DevForge-Setup-vX.Y.Z.exe`). Toutes les versions, avec leurs notes, sont sur la [page des releases](https://github.com/victhille/devforge/releases).

## Configuration requise

- Windows 10 ou 11, 64 bits (x64).
- Facultatif, selon ce dont tu te sers : [Git](https://git-scm.com), [Docker Desktop](https://www.docker.com/products/docker-desktop/), Node.js, PHP… La page [Environnement](/devforge/system/environment/) indique ce qui est installé et propose de le faire.

## Installer

<Steps>

1. Lance `DevForge-Setup-vX.Y.Z.exe`.
2. Windows peut afficher **« Windows a protégé votre ordinateur »** : l'installeur n'est pas encore signé. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Choisis le dossier d'installation et termine. DevForge s'ouvre sur l'[écran de bienvenue](/devforge/getting-started/first-launch/).

</Steps>

## Vérifier l'installeur

L'empreinte SHA-256 de l'installeur est affichée sous le bouton et dans les notes de la version sur GitHub. Pour comparer avec le fichier téléchargé, dans PowerShell :

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\DevForge-Setup-vX.Y.Z.exe"
```

Les deux suites de chiffres et de lettres doivent être identiques. Si elles diffèrent, le fichier a été modifié ou mal téléchargé : supprime-le et télécharge-le à nouveau.

## Mises à jour

DevForge cherche une nouvelle version 15 secondes après son démarrage, puis toutes les 6 heures. Elle se télécharge en arrière-plan et s'installe au prochain redémarrage. Détails : [Installation](/devforge/getting-started/installation/#mises-à-jour-automatiques).

What is coming to DevForge, from the nearest to the furthest. No date is promised: a version ships when it is ready. What has already shipped is in [What's new](/devforge/en/news/).

An idea, a need? Suggest it in the [discussions](https://github.com/victhille/devforge/discussions) or as an [issue](https://github.com/victhille/devforge/issues/new/choose).

## Ready for the next version

Done and in review:

- **Signing in without a token** to **GitHub** in **Settings › Connections**: a code to type on GitHub, instead of pasting a token ([the page](/devforge/en/getting-started/connections/#github)).
- **Expo**: when Windows reserves Metro's port (WSL, Hyper-V), DevForge takes the next free one, instead of staying stuck at startup.

## Next

- **Signing in without a token** to **Vercel**: the browser instead of a token. The code is ready; it waits for Vercel to open its API to apps, still a private beta.

## Towards 1.0

1. A **1.0.0-beta.1 pre-release**, on the **Beta** channel (**Settings › Updates**).
2. Tests on a fresh Windows: install, update from 0.5.0, uninstall.
3. If all goes well, **1.0.0**, once the beta has run for a week with no blocking bug, with an up-to-date video and screenshots.
4. Then an attempt to **sign the installer**, so that Windows SmartScreen no longer distrusts it.

## Under consideration

No other work under consideration for now: share your ideas in the [discussions](https://github.com/victhille/devforge/discussions).
